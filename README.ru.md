# Бот записи для салона «Лилия»

Telegram-бот: прайс, запись к мастеру на время, напоминание за сутки, панель администратора.
Стек: Python 3.11+, aiogram 3, SQLite, APScheduler, один процесс.

## Запуск за 5 минут

```bash
cd salon-booking-bot
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

1. В `.env` вписать `BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. `python main.py`, написать боту `/id` — он покажет ваш Telegram ID.
3. Вписать этот ID в `ADMIN_IDS` в `.env` (несколько — через запятую), перезапустить.
4. `ANTHROPIC_API_KEY` — по желанию. Без него бот всё равно работает: прайс и запись на кнопках,
   а любой свободный вопрос сразу уходит администратору.

Тесты: `pytest -q` (12 штук).

## Что умеет

**Клиент**
- `/start` — приветствие, в котором бот говорит, что он ИИ, и предлагает позвать человека.
- «Услуги и цены» — прайс из базы.
- «Записаться» — услуга → мастер → день → время → телефон (кнопка «поделиться контактом» или вручную) → имя → подтверждение.
- «Мои записи» — список и отмена (не позднее чем за 2 ч).
- «Позвать администратора» — открывает обращение; дальше всё, что пишет клиент, пересылается администратору, пока она не закроет обращение `/done`.
- Свободный текст — модель отвечает **только** по прайсу; остальное передаёт администратору.
- За сутки до визита — напоминание с кнопками «Приду» / «Отменить».

**Администратор** (`/admin` — список)
- `/today`, `/tomorrow`, `/week` — записи с телефонами.
- `/cancel_appt ID` — отменить, клиент получит уведомление.
- `/block Айгуль 2026-09-08 13:00 60` — обед/перерыв, занимает слот как запись.
- `/reply USER_ID текст`, `/done USER_ID` — ответить клиенту и закрыть обращение.
- `/stats` — записей через бота за 30 дней (главная метрика), отмены, напоминания, обращения.
- Уведомления о каждой новой записи и отмене приходят автоматически.

## Где смотреть по чек-листу

| Проверка | Где |
|---|---|
| Слот защищён транзакцией и уникальным индексом | `salon_bot/db.py`: индекс `ux_master_slot` (частичный, по активным записям), `Database.book()` — `BEGIN IMMEDIATE` + проверка пересечений + INSERT; `IntegrityError` → `SlotTaken`. Тест гонки: `tests/test_core.py::test_race_two_clients_same_slot` |
| Модель отвечает только по прайсу | `salon_bot/llm.py`: системный промпт получает только прайс; ответ JSON `{answer, handoff}`; любое сомнение, ошибка, таймаут, пустой ответ → `handoff=True` |
| Телефон не попадает в промпт | `llm.py` не получает ничего, кроме текста сообщения; `scrub()` маскирует номер, если клиент написал его сам. Тест: `test_scrub_hides_phone_before_llm` |
| Первое сообщение: «я ИИ» + позвать человека | `salon_bot/handlers/start.py`: `WELCOME`, кнопка «Позвать администратора» в главном меню |
| Напоминания в базе, переживают перезапуск | таблица `reminders` (`send_at`/`sent_at`), `salon_bot/reminders.py`: планировщик раз в минуту опрашивает базу; после рестарта дошлёт просроченное. Тест: `test_reminder_persisted_and_due` |
| Администратор по whitelist ID | `ADMIN_IDS` в `.env` → `Settings.admin_ids`; фильтр `IsAdmin` в `handlers/common.py` закрывает весь роутер `handlers/admin.py` |

## Допущения (в тестовом прайсе, у Лилии не уточнены)

Зашито в `salon_bot/seed.py` и `.env`:
- длительности: стрижка 60, окрашивание 150, маникюр 60, маникюр с покрытием 90, брови 30, ресницы 90 мин;
- кто что делает: Айгуль — стрижка, окрашивание; Динара — маникюр; Марина — стрижка, брови, ресницы;
- сетка слотов 30 мин, запись открыта на 14 дней, напоминание за 24 ч, отмена не позднее чем за 2 ч;
- максимум 2 активные записи на одного клиента (защита от спама);
- обед мастера вносит администратор командой `/block`.

## Структура

```
main.py                    точка входа, сборка Dispatcher и планировщика
salon_bot/config.py        настройки из .env
salon_bot/db.py            схема, транзакция записи, напоминания, обращения
salon_bot/seed.py          тестовый прайс и мастера
salon_bot/llm.py           модель: только прайс, маскировка PII, fallback на человека
salon_bot/reminders.py     тик планировщика
salon_bot/keyboards.py     клавиатуры и форматирование дат
salon_bot/handlers/        start (меню), booking (FSM записи), admin, chat (свободный текст)
tests/test_core.py         гонка за слот, пересечения, напоминания, маскировка телефона
```

Известные упрощения демо: FSM в памяти (незавершённая запись сбрасывается при рестарте), один процесс, SQLite без бэкапов. Для продакшена: Redis для FSM, бэкап базы, systemd-юнит.
